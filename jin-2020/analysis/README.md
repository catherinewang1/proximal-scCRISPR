Some analysis of jin-2020 data.

Some subfolders looking at different subsets of the data

`1_causarrayexampledata`- data provided by the example tutorial from causarray

`2_fulldata`- larger dataset from data provided at GEO site and cleaned/merged using the data from Broad website.

  + GEO- raw counts
  + Broad- subselected cells + cell types + other cell covariates

 `3_fulldataexcitatoryneurons`- similar to full data (previous notebook), but subsetting only for excitatory neurons.

 `4_excneur_unpert`- similar to fulldataexcitatoryneurons (previous notebook), but using many unperturbed excitatory neuron cells as controls
